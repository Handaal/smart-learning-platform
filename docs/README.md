## Quick Reference

### Platform at a Glance

```
Name:          STEP (Smart Training & Emotion Platform)
Domain:        Instructional Design Project Management (IDPM)
Target Users:  Content developers, e-learning authors, LMS administrators
Duration:      8-week training program (16 sessions, ~90 min each)
Modules:       5 core modules, 20 episodes
Study Design:  Quasi-experimental (N ≥ 60, experimental vs. control)
```

## Key Design Principles

1. **Emotion as signal, not surveillance** — facial data processed client-side, never transmitted as raw video
2. **Adaptive invisibility** — interventions feel helpful, not algorithmic
3. **Competence-affirming** — all feedback oriented to growth, never punitive gating
4. **Privacy by architecture** — consent is granular, layered, and always revocable
5. **Research-instrumentable** — every interaction is logged to enable mixed-methods study
